\# Historias de Usuario – MVP



\## HU-01

Como miembro del comité,

quiero registrar los gastos del mes,

para calcular correctamente los gastos comunes.



\## HU-02

Como sistema,

quiero prorratear los gastos según coeficiente,

para asegurar un cálculo justo.



\## HU-03

Como residente,

quiero ver mi estado de cuenta,

para saber cuánto debo y por qué.



\## HU-04

Como tesorero,

quiero registrar pagos,

para mantener actualizada la morosidad.



\## HU-05

Como comité,

quiero ver un listado de morosos,

para tomar acciones oportunas.
