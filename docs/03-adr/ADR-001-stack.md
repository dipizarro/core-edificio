\# ADR-001: Stack tecnológico



\## Decisión

Se utilizará ASP.NET Core 8 + SQL Server + Azure.



\## Motivo

\- Stack enterprise probado

\- Experiencia del desarrollador

\- Facilidad de despliegue y escalabilidad

\- Buen encaje como proyecto de portafolio



\## Consecuencias

\- Mayor robustez

\- Mayor complejidad inicial
