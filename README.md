\# CoreEdificio



CoreEdificio es una plataforma de autoadministración para comunidades y edificios,

diseñada para entregar trazabilidad, transparencia y control operativo,

cumpliendo la Ley de Copropiedad Inmobiliaria chilena (Ley 21.442).



\## Objetivo

Resolver la gestión de gastos comunes, pagos, morosidad y documentación

en comunidades sin administrador o con administración deficiente.



\## Stack

\- ASP.NET Core 8 (Web API)

\- SQL Server (Docker local / Azure SQL en producción)

\- Azure App Service

\- Azure Blob Storage
